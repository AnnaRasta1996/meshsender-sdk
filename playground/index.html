English Video Walkthrough

What the Android prototype footage shows, and why each surface matters. Same verified narrative as docs/DEMO_VIDEO_GUIDE.md. Watch: https://www.youtube.com/watch?v=K9X8EYo6-CE.

  • Account registration and recovery — on-device onboarding so users can join and restore access without treating centralized reset flows as the only path to sovereignty.
  • Internet messaging between two devices — when the network works, MeshSender still carries normal conversations; offline-first does not mean offline-only.
  • Mesh Mode and offline communication — prototype UI for continuing when continuous internet fails. Open SDK readiness: physical radios remain PENDING; footage alone does not certify multi-hop routing or LoRa hardware.
  • Same-conversation close-up — a tighter view of the chat for improved readability on phone and desktop screens.
  • Offline Map and network visualization — spatial context for nodes without depending on live cloud map connectivity.
  • Integrated wallet and Phantom interface — Solana-oriented wallet UX in the prototype. This Playground keeps economic gates OFF (no signing or spend).
  • CPX on Solana mainnet — Chaos Paradox is a real mainnet mint; the Playground can live-read it. Production settlement execution is not claimed from the video.
  • Existing Solana mainnet infrastructure — before this hackathon, the project already established a live CPX mint and a Squads Protocol V4 multisig Treasury on Solana mainnet (historical ~150B CPX Treasury funding; Reward Reserve separate). Treasury / Reserve addresses stay in the private product and are not published here. This Open SDK does not claim native Squads transaction integration, Seed Vault integration, or live automatic settlement — those remain OFF. The custom settlement program is not treated as a deployed live execution path in this demo.
  • Global vision — communication that survives outages, with an economy designed to reward participation. The Interactive Playground below proves public-safe building blocks with explicit labels.
  • Android prototype → Open SDK — the film is the earlier product surface; this package is the Hackathon Flagship Open SDK (simulated lab, synthetic proofs, non-spending economy quotes, live mint inspection).
